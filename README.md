## Инструкция по созданию карточек:
- создать `.json` файл в `resources/cards`.
- вставить и заполнить заготовку.
- вставить имя `.json` файла в скрипт страницы(в лист `cards`), без расширения.

## Заготовка:
```json
{
    "title": "",
    "description": "",
    "date": "",
    "size": "",
    "img": ".png"
}
```

### Инструкции по заполнению заготовки:
- title - любая строка. Заголовок карточки.
- description - любая строка. Описание карточки. Все переходы на новую строчку надо заменить на `<br>`.
- date - любая строка, но желательно: `XXXXг.`. Дата карточки, видна не на всех видах.
- size - `normal`/`midium`/`exstra`/`unreasonable`. Размер карточки.
- img - изображение, обычно квадратное и желательно в формате `.png`. Иконка/банер карточки. Иконка - всегда должна быть квадратной, а размеры банеров луче брать с уже существующих.
